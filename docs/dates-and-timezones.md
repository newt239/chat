# 日付ジャンプ・時刻表示・タイムゾーン

メッセージの日時まわりの設計。

## 時刻のツールチップ

- メッセージ・システムメッセージの時刻（チャンネル・スレッド・スレッド一覧で共通の `MessageTime`）は、ホバーとキーボードのフォーカスで曜日と秒を含む日時をツールチップに出す。`title` 属性はタッチやキーボードで読めないため使わない。
- 時刻の要素はツールチップのためだけにフォーカスを受ける。押しても何も起きないので、ボタンやリンクではなく `role="img"` にしている（React Aria の `Focusable` が説明を読み上げる役割として受け付けるもの）。

## 日付区切り

- タイムラインを端末のタイムゾーンの日付ごとにまとめ、各日の先頭に区切りを置く。区切りの日付はその日の範囲の中だけで上部に固定し、線はその場に残す。
- 区切りを押すとメニュー（今日・昨日・先週・先月・最初・日付を指定）を開く。「日付を指定」は React Aria の Calendar で、今日より後の日は選べない。
- 日付は `?date=YYYY-MM-DD`（最初は `?date=first`）で表す。リンクで共有でき、戻る操作で元の位置に戻れる。移動するときは `?message=` を外す。

## ListMessages の around

- `around` を指定すると、その日時より前の `limit` 件と、その日時以降の `limit` 件をまとめて返す。`has_more` は前に、`has_newer` は後に続きがあるかを表す。`(channel, created_at)` のインデックスを前後それぞれの向きに読むだけで済む。
- 日付ジャンプはその日の 0 時（端末のタイムゾーン）を `around` に渡し、以降で最初の投稿へスクロールしてハイライトする。
- 続きは従来どおり `until`（前）と、新たに `since` だけの指定（後）で読み込む。`since` だけのときは直後から古い順に取るように変えた（従来はこの指定を使う呼び出し元がなかった）。
- 日付へ移動して最新まで読み込んでいないあいだは、新着を受け取っても表示が途切れるため既読にしない。「最新のメッセージへ移動」で `?date=` を外す。

## タイムゾーン

- `User` の設定（`UserPreferences`）に IANA 名の `timezone`（空は未設定）と、自動更新するかの `timezone_auto_update` を持つ。名前の正しさはサーバーの `time.LoadLocation` で確かめ、サーバー自身を指す `Local` は受け付けない。
- 起動時に `Intl.DateTimeFormat().resolvedOptions().timeZone` を保存値と比べる。未設定か自動更新が有効なら尋ねずに保存し、それ以外は更新するかをトーストで尋ねる（1 回の起動につき 1 回）。GeoIP は使わない。端末の設定の方が正確で、追加のデータベースも要らないため。
- 設定画面の「表示」で手動で選べる。候補は `Intl.supportedValuesOf("timeZone")`。
- ワークスペースのメンバー一覧に `timezone` を含め、プロフィールに相手の現地時刻を出す。それ以外の日時の表示は端末のタイムゾーンのまま。
