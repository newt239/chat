# メッセージの UI

メッセージ一覧・入力欄・リアクション・ピン留め・ブックマーク・通知の画面の設計判断です。見た目の基準は North Star モックの `.msg` / `.md` / `.tools` / `.composer` / `.rx` / `.tsum` / `.sheet` です。

## 操作の出し方

- デスクトップはホバー（マウスのみ）かフォーカスでツールバーを出す。位置はメッセージの上端より上（`-top-7`）にし、コードブロックのコピーボタンと重ならないようにする。一覧の先頭には、はみ出す分の余白を取る。
- メニューや絵文字ピッカーを開いている間は、ポインタが外れてもツールバーを残す（`onOverlayOpenChange`）。
- モバイルはツールバーを出さず、長押し（450ms、8px 以上動いたらスクロールとみなして取り消す）か右クリックでボトムシートを開く。シートは `DialogFrame` の `bottom` レイアウトで、`transitions.sheet` で出入りする。
- 「その他」メニューとシートの項目は `useMessageMenuActions` の同じ定義から作る。「スレッドを新しいタブで開く」は `href` を持つ項目として `<a target="_blank">` で描き、⌘ / Ctrl クリックや中クリックはブラウザに任せる。モバイルのシートには出さない。
- 削除は `AlertDialog` で確認してから行う。

## 表示

- 時刻は `formatTime`、ツールチップに `formatDateTime`。スレッドの最終返信は `formatRelativeTime`。人名の列挙は `Intl.ListFormat`。
- Markdown の見た目は `markdownClassName`（本文とプレビューで共有）。本格的な整備は #14 で行う。
- 投稿欄の書式ボタンはコンテナクエリで幅が足りるとき（スレッド欄やモバイル以外）だけ出す。高さは `field-sizing: content` で内容に合わせる。
